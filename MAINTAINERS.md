# Maintainers

RepoDoctor is currently maintained by the repository owner.

## Responsibilities

- Review issues and pull requests.
- Keep the CI checks and security policy current.
- Create releases and update the changelog.
- Triage and coordinate vulnerability reports according to `SECURITY.md`.

## Becoming a maintainer

Regular contributors may be invited to become maintainers after demonstrating
constructive participation, sound technical judgment, and an understanding of
the project's security and community expectations.

## Releases

Maintainers update `CHANGELOG.md`, run the full quality suite, create an
annotated version tag, publish the package when appropriate, and create the
corresponding GitHub release.
